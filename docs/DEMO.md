# Быстрый прогон (happy path, ~5 минут)

Короткий сценарий «потрогать» основные потоки на **staging**. Для полной
приёмки перед запуском используйте [testing-checklist.md](testing-checklist.md).

> ⚠️ Только на **staging-ресурсах** (тестовый канал/чат). Не запускайте бота
> против боевых канала/чата при тесте — это затронет реальных участников.

## Что понадобится
- Браузер на `https://community.example.com` (портал) и на админке (`<ip>.sslip.io`).
- Telegram на `@membership_bot`.
- Тестовая карта Stripe `4242 4242 4242 4242` · CVC `123` · любая будущая дата
  (если Stripe в test-режиме), либо реальный мелкий платёж с последующим возвратом.

---

## 1. Подписка через Stripe (~60 сек)
1. Бот → `/start` → «Подписка» → «Месяц» → «Карта (Stripe)».
2. На Stripe Checkout оплатите тестовой картой.
3. Бот пришлёт **две** одноразовые инвайт-ссылки — в закрытый канал и в чат
   проработок. Перейдите по обеим.
4. В админке на дашборде обновились MRR и график выручки.

## 2. Веб-портал по magic-ссылке (~45 сек)
1. У активного подписчика бот даёт ссылку на портал.
2. Перейдите — вход одноразовый (ссылка живёт ~15 мин), дальше держится сессия.
3. Внутри: модули → видео → плеер Vimeo.
4. У пользователя с истёкшей подпиской портал закрыт.

## 3. Реферал (~90 сек)
1. Бот → «Кабинет» → скопируйте реф-ссылку (`?start=ref_XXXXXXXX`).
2. Откройте её со второго аккаунта → `/start` → «Вас пригласил …».
3. Второй оплачивает **месячный** тариф → скидка только на первый месяц.
4. Пригласившему **+7 дней**, приглашённому **+3 дня**; в админке → «Рефералы»
   он в лидерборде, комиссия в статусе pending (вестинг 3 мес).

## 4. USDT и ручная оплата (~90 сек)
1. Бот → «Подписка» → «Месяц» → «USDT TRC20» (или ERC20).
2. Бот покажет адрес и сумму; отправьте и пришлите **хеш транзакции**.
3. После 3 подтверждений доступ выдаётся **автоматически**.
4. Ручная оплата: пользователь шлёт подтверждение → админка → «Модерация» →
   «Одобрить» → бот выдаёт доступ. (Zelle на запуск скрыт фиче-флагом.)

## 5. Промокод (~45 сек)
1. Админка → «Промокоды» → создайте процентный/фиксированный код.
2. В боте на шаге оплаты введите код → скидка применяется (с реф-скидкой не
   складывается, приоритет у промокода).

## 6. Возврат (~45 сек)
1. Админка → «Платежи» → «Возврат» по транзакции.
2. Полный возврат: доступ к порталу пропадает сразу, из канала/чата удаляют,
   реф-комиссия корректируется.

## 7. Дашборд
Откройте `/` админки: KPI (MRR/активные/новые/churn), график выручки, топ
рефереров, последние платежи, счётчик очереди модерации в сайдбаре.

## Если что-то не работает

| Проблема | Что проверить |
|---|---|
| Бот не отвечает | `docker compose -p membership_saas logs -f bot` |
| После оплаты ничего | Stripe webhook смотрит на `…/webhooks/stripe` и `STRIPE_WEBHOOK_SECRET` в `.env`? |
| Юзер не попадает в канал/чат | Бот — админ в **обоих** ресурсах? `PRIVATE_CHANNEL_ID`/`PRACTICE_CHAT_ID` верные (staging)? |
| `/health` отдаёт 503 | Норма, если бот остановлен (`bot.stale:true`, `db.ok:true`). Запустите `bot`. |
| Портал не пускает | Magic-ссылка одноразовая и живёт 15 мин — возьмите свежую в боте. |
| Админка не открывается | `docker compose -p membership_saas logs -f caddy` — SSL подтягивается до ~30 сек. |
